# Realms Rumble — Godot 4 starter

A first local two-player platform-fighter prototype: Gandalf vs. Darth Vader.

## Run
1. Install Godot 4.3 or newer: https://godotengine.org/download/
2. Extract this ZIP.
3. In Godot, choose **Import** and select `project.godot`.
4. Press **F5** to run.

## Controls
- Gandalf / Player 1: A/D move, W jump, F staff strike, G lightning special.
- Darth Vader / Player 2: Left/Right move, Up jump, K lightsaber strike, L Force special.

## Included
- Local two-player movement and jumping
- Three stocks each; damage percentage increases knockback
- Four platforms, respawn, simple attacks and visual hit effects
- Placeholder vector-drawn character silhouettes
